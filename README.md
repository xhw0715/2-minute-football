# 2 Minute Football

A fast-paced American football game built with Next.js where you play as a quarterback leading your team to victory in just 2 minutes.

## Features

- **Fast-paced gameplay**: Each game lasts exactly 2 minutes
- **Quarterback simulation**: Control passing mechanics and team strategy
- **Mobile-friendly**: Responsive design works on all devices
- **Free to play**: No downloads or registration required
- **Unblocked**: Play anywhere, anytime

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.Alternatively, you can open it https://coreball.cc

## Game Instructions

1. Drag your mouse or finger to move your quarterback
2. Use the targeting line to aim your pass toward receivers
3. Release to throw the ball - timing is crucial!
4. Guide receivers past defenders into the end zone for touchdowns

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Language**: JavaScript
- **Deployment**: Vercel/Netlify ready
